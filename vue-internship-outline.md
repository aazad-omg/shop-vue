# 3-Month Frontend Internship — Project Requirements

## Objective

Build a **unique real-world frontend application of your own choice** using the Vue ecosystem.

This is **not a fixed project**. The requirements below define what your project should demonstrate.

Your final project should be substantial enough to showcase your ability to build a **production-style frontend application**.

---

## 1. Technology

### Required

- Vue 3
- Vite
- TypeScript
- JavaScript
- Vue Router
- Git / GitHub

### Use where appropriate

- Pinia
- VueUse
- Axios / Fetch
- UI/component libraries
- Tailwind CSS
- Vitest / Vue Test Utils
- Playwright / Cypress
- Other Vue ecosystem libraries

Choose libraries based on the problem, not just to increase the tech stack.

---

## 2. Project

Choose a product that:

- Solves a real or meaningful problem
- Has a clear target user
- Contains multiple user workflows
- Goes beyond basic CRUD
- Includes at least **one technically challenging feature**

Possible areas: education, finance, productivity, analytics, e-commerce, project management, communication, developer tools, scheduling, AI, etc.

---

# 3. Milestones

## Milestone 1 — Product Definition

- [x] Define the problem
- [x] Define target users
- [x] Define core features
- [x] Define key user flows
- [x] Define project scope
- [] Create basic wireframes/design
- [] Document initial requirements

---

## Milestone 2 — Foundation & Architecture

- [] Set up Vue + Vite + TypeScript
- [] Configure ESLint and Prettier
- [] Set up Git repository/workflow
- [] Define project structure
- [] Define component architecture
- [] Set up routing
- [] Decide state management approach
- [] Define API/data layer
- [] Configure environment variables

---

## Milestone 3 — Core Application

- [ ] Build application layout
- [ ] Implement main pages
- [ ] Create reusable components
- [ ] Implement major user workflows
- [ ] Integrate API or realistic data source
- [ ] Implement appropriate state management
- [ ] Build forms and validation
- [ ] Handle loading, empty, and error states
- [ ] Implement responsive UI

---

## Milestone 4 — Advanced Engineering

- [ ] Create reusable composables/utilities
- [ ] Demonstrate strong TypeScript usage
- [ ] Implement authentication/authorization where relevant
- [ ] Add at least one technically challenging feature
- [ ] Handle important edge cases
- [ ] Improve API/data handling
- [ ] Apply appropriate Vue patterns and ecosystem tools

---

## Milestone 5 — Production Quality

- [ ] Review and improve performance
- [ ] Review accessibility
- [ ] Complete mobile/tablet support
- [ ] Add meaningful automated tests
- [ ] Refactor duplicated or unnecessary code
- [ ] Remove unused dependencies/code
- [ ] Verify production build
- [ ] Ensure proper error handling
- [ ] Ensure no secrets are committed

---

## Milestone 6 — Documentation & Presentation

- [ ] Complete README
- [ ] Document setup and environment configuration
- [ ] Document major features
- [ ] Document architecture and important decisions
- [ ] Add screenshots/demo
- [ ] Document known limitations
- [ ] Prepare final presentation
- [ ] Prepare a live product demo
- [ ] Prepare one technical deep dive

---

## 4. Code Quality

Your project should demonstrate:

- Strong TypeScript usage
- Clear naming
- Consistent structure
- Reusable logic
- Minimal duplication
- Appropriate component boundaries
- No unnecessary complexity
- Clean Git history
- Maintainable code

---

## 5. Final Presentation

Present:

### Product

- Problem
- Target users
- Main features
- Live demo

### Engineering

- Architecture
- State management
- API/data handling
- Reusable components/composables
- Important technical decisions
- Main challenges and solutions

### Technical Deep Dive

Explain one challenging part of the project:

- Problem
- Chosen approach
- Alternatives considered
- Trade-offs
- Possible future improvements

---

## Core Expectation

**Do not treat this as a tutorial or fixed project specification.**

Use these milestones as a **checklist of skills and outcomes**.

Each intern should build a different product while demonstrating that they can:

**Plan → Design → Architect → Build → Test → Optimize → Present a real frontend application.**
